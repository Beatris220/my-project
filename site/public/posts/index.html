Этап 1: Инициация проекта и патентные исследования

Проведен детальный анализ рынка инди-симуляторов повседневности. На основе полученных данных сформирована концепция игры «Симулятор раздачи листовок».

Проведены патентные исследования по ГОСТ 15.011–96, подтвердившие полную юридическую чистоту наших механик. Сформирован совместный репозиторий на GitHub для контроля версий кодовой базы.
