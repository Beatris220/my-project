#  Проект: «Симулятор раздачи листовок» — Интерактивный Telegram-бот

##  Описание практики
В рамках учебной (проектной) практики выполнена разработка игрового Telegram-бота с нуля, без использования высокоуровневых фреймворков (`aiogram`, `pyTelegramBotAPI`). Проект направлен на закрепление навыков работы с REST API, HTTP-протоколом, модульной архитектурой на Python, а также на освоение командной разработки через Git и подготовку технической документации в формате Markdown.
